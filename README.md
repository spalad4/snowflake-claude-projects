# Snowflake + Claude Projects

A personal learning repository for developing data science skills using AI, exploring Claude's latest capabilities, and building real-world use cases with Snowflake.

## Goals

- Build hands-on data science skills through AI-assisted projects
- Explore and showcase new Claude AI features as they ship
- Develop end-to-end use cases combining Snowflake + Claude
- Document learnings and patterns for reuse

## Repository Structure

```
snowflake-claude-projects/
│
├── data-science/          # Core data science projects
│   ├── eda/               # Exploratory data analysis
│   ├── ml/                # Machine learning models
│   └── visualization/     # Charts, dashboards, storytelling
│
├── snowflake/             # Snowflake-specific work
│   ├── cortex/            # Snowflake Cortex AI features
│   ├── queries/           # SQL patterns and optimizations
│   └── integrations/      # Connecting Snowflake to external tools
│
├── claude-features/       # Claude AI feature explorations
│   ├── tool-use/          # Function calling and tool use
│   ├── extended-thinking/ # Complex reasoning with extended thinking
│   ├── vision/            # Image and document analysis
│   └── agents/            # Multi-step agentic workflows
│
├── use-cases/             # End-to-end business use cases
│   ├── analytics/         # Analytics and reporting automation
│   ├── data-pipelines/    # AI-assisted data pipeline generation
│   └── nlp/               # Natural language interfaces to data
│
└── notebooks/             # Jupyter notebooks for exploration
```

## Tech Stack

- **Data Warehouse**: Snowflake
- **AI / LLM**: Claude (Anthropic API)
- **Languages**: Python, SQL
- **Tools**: Claude Code, Jupyter, dbt (planned)
